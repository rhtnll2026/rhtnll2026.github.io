第 1 题

油纸伞制作中的化学

返回原卷说明与一、选择题

题目与已知条件

中国油纸伞已有千年历史，其制作过程包括碱法制浆(纸浆)、柿漆(含单宁酸，属于多酚类物质)粘结、朱砂(HgS)附着和桐油防水等工艺，下列说法错误的是

A.

“碱法制浆”工艺未涉及化学变化

B.

柿漆中的单宁酸能形成分子间氢键

C.

朱砂是一种无机颜料

D.

桐油由桐树种子榨取，有疏水性

所用高中知识

化学变化的判断；氢键；无机颜料；油脂的疏水性。

读题与思路

碱法制浆要用碱溶解、降解木质素等，生成了新物质。

分步解析

  1. 碱法制浆用NaOH等蒸煮原料，木质素、半纤维素发生水解、降解等反应，涉及化学变化，A错误。
  2. 单宁酸含大量酚羟基，可形成分子间氢键，B正确。
  3. HgS是无机物，朱砂是传统无机颜料，C正确。
  4. 桐油属于油脂，难溶于水，具有疏水性，D正确。

答案

A

检查与易错点

“制浆”不是单纯的物理粉碎，碱法蒸煮中发生了化学反应。

第 3 题

方程式正误

返回原卷说明与一、选择题

题目与已知条件

化学知识在生产、生活中应用广泛。下列反应方程式错误的是

A.

氢氟酸溶蚀玻璃生产磨砂玻璃：4HF + SiO₂ ══ SiF₄↑ + 2H₂O

B.

侯氏制碱法的主要反应：NH₃ + NaCl + CO₂ + H₂O ══ NH₄Cl + NaHCO₃↓

C.

酸性高锰酸钾溶液测定空气中的SO₂含量：5SO₂ + 2MnO₄⁻ + 2H₂O ══ 5SO₄²⁻ + 2Mn²⁺ + 4H⁺

D.

醋酸除去水垢中的CaCO₃：2H⁺ + CaCO₃ ══ Ca²⁺ + CO₂↑ + H₂O

所用高中知识

离子方程式书写中弱电解质不拆。

读题与思路

逐项检查物质拆分与守恒。

分步解析

  1. A、B均为课本反应，书写正确。
  2. C：S由+4升至+6失2e⁻×5，Mn由+7降至+2得5e⁻×2，电荷、原子均守恒，正确。
  3. D：醋酸为弱酸，应写化学式：2CH₃COOH + CaCO₃ ══ Ca²⁺ + 2CH₃COO⁻ + CO₂↑ + H₂O，D错误。

答案

D

检查与易错点

醋酸是弱电解质，离子方程式中不能拆成H⁺。

本题来源：doc-hunan-q

三氯异氰尿酸相关化学用语

返回原卷说明与一、选择题

题目与已知条件

消毒剂三氯异氰尿酸()能与H₂O持续缓慢反应产生HClO。下列相关化学用语表述正确的是

A.

三氯异氰尿酸的分子式：Cl₃N₃O₃

B.

HClO的电子式：

C.

基态Cl的价层电子排布式：3s²3p⁵

D.

H₂O的空间填充模型：

所用高中知识

分子式、电子式、价层电子排布、空间填充模型。

读题与思路

逐项对照结构。

分步解析

  1. 结构中含3个C、3个N、3个O、3个Cl，分子式为C₃Cl₃N₃O₃，A漏写C，错误。
  2. HClO中O为中心原子，电子式为H:O:Cl（O、Cl各补齐孤电子对），图中写成H—Cl—O的顺序，B错误。
  3. Cl为17号元素，价层电子排布式3s²3p⁵，C正确。
  4. H₂O为V形，空间填充模型应是一个大球（O）连两个小球（H）；图示为两个等大的球，D错误。

答案

C

检查与易错点

HClO的结构是H—O—Cl，不能按化学式顺序写电子式。

所用高中知识

氢卤酸酸性、氢键、同分异构体沸点、晶体硬度。

读题与思路

判断“解释”能否推出“性质”。

分步解析

  2. H₂O沸点高于HF是因为每个H₂O形成的氢键数目更多；单个氢键键能HF更大，不能解释H₂O沸点更高，B错误。

C

检查与易错点

判断此类题要看因果关系是否成立，而不只看两句话分别是否正确。

第 6 题

短周期元素推断

返回原卷说明与一、选择题

题目与已知条件

W、X、Y、Z、M为原子序数依次增大的短周期主族元素，W与X位于不同周期，X在同周期基态原子中未成对电子数最多，Y与Z同族。下列说法错误的是

A.

第一电离能：X<Y

B.

热稳定性：W₂Y>W₂Z

C.

ZY₂、MY₂的空间结构均为V形

D.

XY₂、ZY₂分别与H₂O反应的反应类型不同

所用高中知识

元素推断；第一电离能的反常；VSEPR模型。

读题与思路

由W₂Y、ZY₂等组成确定元素。

分步解析

  1. W₂Y、W₂Z形式且Y、Z同族，结合W与X不同周期，W为H；X为第二周期未成对电子最多的N；Y为O，Z为S，M为Cl。
  2. A：N的2p半充满，第一电离能N>O，A错误。
  3. B：非金属性O>S，H₂O比H₂S稳定，B正确。
  4. C：SO₂、ClO₂中心原子均有孤电子对（ClO₂含单电子），均为V形，C正确。
  5. D：3NO₂ + H₂O ══ 2HNO₃ + NO为氧化还原反应，SO₂ + H₂O ⇌ H₂SO₃为化合（非氧化还原）反应，类型不同，D正确。

答案

A

检查与易错点

N的第一电离能大于O，是第二周期的常见反常点。

第 7 题

Li-Ag₂CrO₄扣式电池

一种可用于心脏起搏器的扣式电池部分截面结构如图所示(LiClO₄-有机溶剂作电解质溶液，Ag₂CrO₄难溶于该溶剂)。下列说法错误的是

A.

往Ag₂CrO₄电极材料中添加石墨，可增强其导电性

B.

正极反应式为Ag⁺ + e⁻ ══ Ag

C.

B

检查与易错点

难溶电极材料不能拆写成离子参加电极反应。

第 8 题

乙炔合成氨基酸

返回原卷说明与一、选择题

题目与已知条件

乙炔是重要的化工原料。一条由乙炔合成某氨基酸的路线如下：

HC≡CH→催化剂HCNH2C=CH−CN→NH3H2NCH2CH2CN→2)H+1)OH−H2NCH2CH2COOH\mathrm{HC{\equiv}CH}\xrightarrow[\text{催化剂}]{\mathrm{HCN}}\mathrm{H_2C{=}CH{-}CN}\xrightarrow{\mathrm{NH_3}}\mathrm{H_2NCH_2CH_2CN}\xrightarrow[2)\,\mathrm{H^+}]{1)\,\mathrm{OH^-}}\mathrm{H_2NCH_2CH_2COOH}

下列说法错误的是

A.

HC≡CH可与H₂O反应生成乙醛

B.

H₂C=CH—CN是极性分子

C.

H₂NCH₂CH₂CN具有碱性，可与盐酸反应

D.

H₂NCH₂CH₂COOH属于α-氨基酸

所用高中知识

乙炔水化；分子极性；胺的碱性；α-氨基酸的定义。

读题与思路

看氨基所在碳的位置。

分步解析

  1. 乙炔在催化剂作用下与水加成生成乙醛，A正确。
  2. 丙烯腈结构不对称，—CN极性强，是极性分子，B正确。
  3. —NH₂有孤电子对，显碱性，可与盐酸成盐，C正确。
  4. H₂NCH₂CH₂COOH中氨基连在羧基的β位碳上，为β-氨基酸（β-丙氨酸），D错误。

答案

D

检查与易错点

α-氨基酸要求氨基与羧基连在同一个碳原子上。

第 10 题

二苯甲酮的制备装置

返回原卷说明与一、选择题

题目与已知条件

实验室用苯和苯甲酰氯在AlCl₃催化下制备二苯甲酮的简易装置如图所示。

已知：①

②苯甲酰氯易水解。

下列说法错误的是

A.

装置中冷凝器的进水口为b

B.

c中可装入无水氯化钙

C.

实验结束时，应先停止加热再移出漏斗

D.

HCl的持续逸出可促进反应正向进行

所用高中知识

冷凝水“下进上出”；防水解的干燥装置；防倒吸；平衡移动。

读题与思路

结合图中冷凝器的接口位置判断。

分步解析

  1. 冷凝器冷却水应从位置较低的接口进入、较高的接口流出，使夹套充满冷却水；图中a接入内管通到下部，应为进水口，b为出水口，A错误。
  2. 苯甲酰氯易水解、AlCl₃遇水也会水解，c处干燥管装无水CaCl₂可阻止烧杯中水蒸气进入，B正确。

  4. HCl是产物，不断逸出使平衡正向移动，D正确。

答案

A

检查与易错点

冷凝水应“下进上出”，不可从上端进水。

第 11 题

铜铁混合物的转化

返回原卷说明与一、选择题

题目与已知条件

常温下，铜铁混合物(粉末状)能发生如图所示的转化关系。下列说法错误的是

A.

溶液h可能是盐酸

B.

向溶液b中通入过量气体e，空气中久置后可得沉淀g

C.

固体残渣中有铜，可能有铁

D.

溶液f中含有[Cu(NH₃)₄]²⁺

所用高中知识

Fe、Cu的性质；Cl₂氧化Fe²⁺；氨水与Fe³⁺、Cu²⁺。

读题与思路

黄绿色气体c为Cl₂，气体e为NH₃，红褐色沉淀g为Fe(OH)₃，深蓝色溶液f含[Cu(NH₃)₄]²⁺。

分步解析

  1. 溶液a过量，铜铁混合物中还原性更强的Fe优先、完全反应；只有Cu可能剩余（若a为盐酸，Cu不反应；若a为FeCl₃，Cu可能部分剩余）。
  2. A：h过量回到a，若为盐酸能溶Fe留Cu，符合流程，A正确。
  3. B：溶液b含Fe²⁺（可能有Cu²⁺），通过量NH₃得Fe(OH)₂，空气中久置被氧化为红褐色Fe(OH)₃，B正确。
  4. C：溶液a过量，Fe必然完全溶解，固体残渣只有Cu，不可能有Fe，C错误。
  5. D：Cu²⁺与过量氨水形成深蓝色[Cu(NH₃)₄]²⁺，D正确。

答案

C

检查与易错点

Fe比Cu活泼，只要溶液a过量，Fe一定先反应完。

本题来源：doc-hunan-q

烯烃是重要的化工原料，可用CO和H₂为原料直接合成，其原理：nCO(g)+2nH2(g)→催化剂CnH2n(g)+nH2O(g)n\mathrm{CO(g)}+2n\mathrm{H_2(g)}\xrightarrow{\text{催化剂}}\mathrm{C}_n\mathrm{H}_{2n}\mathrm{(g)}+n\mathrm{H_2O(g)}。回答下列问题：

（1）该反应的关键在于CO活化路径的调控。图Ⅰ是M₁、M₂（M₁、M₂分别是Co₂C和Cox_xMn1−x_{1-x}O）两种催化剂活化CO的机理，其中催化效率较高的是＿＿＿＿(填“M₁”或“M₂”)。催化剂为M₂时，反应历程中决速步(速率最慢)的反应方程式为＿＿＿＿。

（2）恒压条件下，该反应若改用M₃（Na/FeCx_x@Fe₃O₄）作催化剂，产物中的H₂O还可与CO反应。以生成C₃H₆为例，相关反应如下：

i．CO(g)+2H2(g)⇌13C3H6(g)+H2O(g)\mathrm{CO(g)+2H_2(g)\rightleftharpoons\frac13C_3H_6(g)+H_2O(g)}　ΔH1=−124.6kJ⋅mol−1\Delta H_1=-124.6\ \mathrm{kJ\cdot mol^{-1}}

ii．yCO(g)+yH2O(g)⇌yCO2(g)+yH2(g)y\mathrm{CO(g)}+y\mathrm{H_2O(g)}\rightleftharpoons y\mathrm{CO_2(g)}+y\mathrm{H_2(g)}　ΔH2=−41.2ykJ⋅mol−1\Delta H_2=-41.2y\ \mathrm{kJ\cdot mol^{-1}}

iii．(1+y)CO(g)+(2−y)H2(g)⇌13C3H6(g)+(1−y)H2O(g)+yCO2(g)(1+y)\mathrm{CO(g)}+(2-y)\mathrm{H_2(g)}\rightleftharpoons\frac13\mathrm{C_3H_6(g)}+(1-y)\mathrm{H_2O(g)}+y\mathrm{CO_2(g)}　ΔH3\Delta H_3

①当 y=0.5y=0.5 时，反应iii的 ΔH3=\Delta H_3=＿＿＿＿kJ·mol⁻¹。

②已知反应的平衡常数 KK 与温度 TT 之间符合：lnK=−ΔHRT+C\ln K=-\dfrac{\Delta H}{RT}+C（RR为摩尔气体常数，CC为常数）。当 y=1y=1 时，反应ii和iii的 lnK\ln K 与温度 TT 的数据如表所示，反应iii对应表中数据＿＿＿＿(填“a”或“b”)。

所用高中知识

能量历程图与决速步；盖斯定律；范特霍夫关系；平衡移动；元素守恒计算。

读题与思路

决速步看能垒最大的一步；ΔH越负，lnK随T变化越剧烈。

分步解析

  1. （1）M₁历程中最大能垒较小，催化效率较高。M₂历程中 *HCOH → *CH + *OH 一步（经TS4）的能垒最大，为决速步：*HCOH ══ *CH + *OH。
  2. （2）①iii = i + ii：ΔH3=−124.6+(−41.2×0.5)=−145.2\Delta H_3=-124.6+(-41.2\times0.5)=-145.2 kJ·mol⁻¹。
  3. ②y=1时 ΔH2=−41.2\Delta H_2=-41.2、ΔH3=−165.8\Delta H_3=-165.8 kJ·mol⁻¹；|ΔH|越大，lnK随温度升高下降越快。b从20.3降到0.7、a从6.7降到1.8，反应iii对应b。
  4. ③无水MgCl₂吸水，体系中水蒸气浓度降低，反应ii（CO + H₂O ⇌ CO₂ + H₂）平衡逆向移动，经ii消耗的CO与生成的CO₂减少，CO转化率和CO₂选择性均减小。
  5. ④由iii，生成 13\frac13 mol C₃H₆（含2 mol H）消耗 (2−y) mol H₂（4−2y mol H），氢原子经济性 =24−2y=12−y=\dfrac{2}{4-2y}=\dfrac{1}{2-y}，y增大则增大：水煤气变换参与程度增大，生成等量烯烃净消耗的H₂减少，而烯烃中的氢原子数不变。
  6. ⑤设CO为1 mol：转化0.9 mol，其中生成CO₂ 0.27 mol，生成CH₄ 0.09 mol，生成烯烃(CH₂)ₙ 0.54 mol C。
  7. O守恒：0.9 mol O中0.54 mol进入CO₂，余0.36 mol进入H₂O，H₂O为0.36 mol。
  8. 参加反应的H：烯烃1.08 mol + CH₄ 0.36 mol + H₂O 0.72 mol = 2.16 mol；氢原子经济性 = 1.08 / 2.16 = 50%。

答案

（1）M₁；*HCOH ══ *CH + *OH　（2）①−145.2　②b　③无水MgCl₂吸水，使水蒸气浓度降低，反应ii平衡逆向移动　④增大；y增大，水煤气变换参与程度增大，生成等量烯烃时净消耗的H₂减少，而烯烃中氢原子数不变　⑤50%

检查与易错点

计算氢原子经济性时，“参加反应的H”应按产物中所含的H（或净消耗H₂）计算，变换反应生成的H₂需抵扣。
